# снэпбилд — тестовое задание (Fullstack Developer)

## 1. Что сделано

Лендинг [снэпбилд](https://snapbuild.ru/) воспроизведён на Next.js — все 11 исходных секций
(шапка, hero, лента логотипов, ценностное предложение, табы форматов контента, сравнение,
безопасность, roadmap, FAQ, финальный CTA, подвал) — и дополнен пятью новыми секциями:
**Тарифы**, **Отзывы**, **Кейсы использования**, **Интеграции**, **Форма обратной связи**.
Новые секции встроены в общий поток страницы между существующими блоками, а не вынесены
отдельным демо-блоком в конец.

## 2. Ссылка на опубликованную версию

https://nikolayyaroslavcev.github.io/snap/

## 3. Локальный запуск

```bash
npm install
npm run dev
# http://localhost:3000
```

Сборка (статический экспорт в `out/`):

```bash
npm run build
```

Тесты (Vitest, unit-тесты для `lib/validation.ts`):

```bash
npm test
```

## 4. Стек

Next.js 16 (App Router, статический экспорт `output: 'export'`), React 19, TypeScript,
Tailwind CSS 3.4, Vitest. Без бэкенда, без внешних сервисов, без API-ключей.

## 5. Пять новых секций

1. **Кейсы использования** — сценарии по ролям (маркетинг / дизайн / продажи / продукт), вкладки с карточками результата.
2. **Отзывы** — карусель цитат клиентов с переключателем-точками.
3. **Тарифы** — 3 плана, переключатель «месяц / год» с пересчётом цены.
4. **Интеграции** — карточки возможностей, открывающие модальное окно с подробностями.
5. **Форма обратной связи** — валидация обязательных полей и формата email, инлайн-ошибки, состояние успешной отправки (без реальной отправки на сервер).

## 6. Как анализировалась стилистика исходного сайта

Снимки экрана на трёх ширинах (375 / 768 / 1280) плюс снятие реальных вычисленных стилей через
`getComputedStyle` — цвета, шрифты, радиусы, отступы, брендовые градиенты — а не визуальная
оценка «на глаз». Токены перенесены в `tailwind.config.ts` как единственный источник стиля:
ни одна секция не хардкодит цвет или радиус в обход темы.

## 7. Что воспроизведено из исходника

Шапка (плавающая, с блюром при скролле), hero с фирменным градиентом и превью интерфейса,
лента логотипов клиентов (анимированная бегущая строка), блок ценностного предложения, табы
форматов контента, таблица сравнения с выделением колонки снэпбилд градиентом, блок
безопасности, roadmap-таймлайн, FAQ-аккордеон, финальный CTA на градиентном фоне, подвал —
все 11 секций, в исходном порядке, на реальных вычисленных токенах, а не по памяти. Секции
также плавно проявляются при скролле (`IntersectionObserver`), как в исходнике, с уважением
`prefers-reduced-motion` и no-JS фолбэком.

## 8. Что не удалось / решено иначе

- Шрифт **TT Commons Pro** — коммерческий, лицензия не приобреталась; заменён на близкий по
  пропорциям и начертаниям бесплатный **Inter** (`next/font/google`, с поддержкой кириллицы).

## 9. Что улучшил бы при наличии времени

Точное воспроизведение типографической шкалы исходного сайта; реальная отправка формы через
serverless-функцию (например, GitHub Pages + внешний form endpoint); e2e-тесты (Playwright)
поверх текущих unit-тестов `lib/validation.ts`.
